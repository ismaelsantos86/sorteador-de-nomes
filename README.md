🎲 Sorteador de Nomes Interativo

> Uma aplicação web moderna e intuitiva desenvolvida em **HTML, CSS e JavaScript** para realizar sorteios aleatórios de nomes de forma rápida, divertida e com efeitos visuais.

## 🚀 Funcionalidades

* **Adição Dinâmica:** Adicione nomes individualmente digitando no campo ou pressionando a tecla **Enter**.
* **Validação Inteligente:** O sistema impede nomes em branco ou duplicados na lista.
* **Contador Automático:** Acompanhe em tempo real a quantidade exata de participantes cadastrados.
* **Remoção Individual:** É possível excluir qualquer participante da lista a qualquer momento através do botão de remoção (`❌`).
* **Sorteio com Confetes:** Ao realizar o sorteio, a aplicação exibe o vencedor na tela, emite um alerta e explode uma chuva de confetes (`canvas-confetti`).
* **Opção de Exclusão Pós-Sorteio:** O usuário pode optar por remover automaticamente o vencedor da lista após o sorteio.
* **Reset Completo:** Botão de reinicialização para limpar todos os dados com confirmação de segurança.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais, sem dependências complexas de frameworks:

* **HTML5:** Estrutura semântica da página.
* **CSS3:** Estilização moderna, variáveis customizadas, animações e responsividade.
* **JavaScript (Vanilla):** Manipulação do DOM, controle de eventos, lógica de arrays e interatividade.
* **Canvas Confetti:** Biblioteca externa via CDN para animações de celebração.
